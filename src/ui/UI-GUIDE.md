# UI 가이드 (도트 키트)
설계 원본은 `DESIGN-PIXEL.md` 2절. 색·크기는 아래 토큰만 쓴다.

## 토큰 (`style.css :root`, 팔레트 24색은 `px/palette.css`)
- 색: `--k0..k5`(남색~흰) `--p1 p2`(종이) `--w1 w2`(나무) `--b1..b4`(파랑, 주색 b2) `--g0..g3`(금) `--r1 r2`(빨강) `--or --gn --pu --pk`. 초록(gn)은 그림 전용.
- 집 테마 4개: `--bg --bg-shade --on-bg --on-bg-dim`(바탕 위 글자만). 카드·모달은 항상 종이 `--paper`(p1) / `--paper-2` / `--ink`(k1) / `--dim`(k2).
- 키트 변수: `--face --line --hi --drop --fg`(요소 색), `--d: 2px`(도트 1칸).
- 간격 `--s1..s5` = 4·8·12·16·24. 받침(아래 6px)이 레이아웃에 안 잡히므로 형제 간격은 8 이상.
- 옛 이름(`--accent --gold-* --hot --sh-1 --fs-1..5 --r-*` 등)은 새 값으로 이어 주는 별칭이다. 새 코드에서 쓰지 않는다.

## 글자
- 본문 `--fs-m` 15/21 Galmuri14. 제목·숫자는 Galmuri11 Bold(`--f-bold`): `--fs-s` 12/16, `--fs-l` 24/28, `--fs-xl` 36/40, `--fs-xxl` 48/52.
- `.fb`(1px 덧칠 굵게)는 Galmuri14 15px 글자에만 쓴다. Galmuri11 Bold(12px)에 얹으면 획이 뭉친다. 아이콘은 도트 자연 크기의 정수배(16도트 32px, 24도트 48px)로만 쓰고 자리가 좁으면 뺀다.
- 줄높이 − 글자 크기는 짝수. `font-weight` 800~900 지정 금지(굵기는 Bold 글꼴로만). `font-synthesis: none`.

## 금지
- 0이 아닌 `border-radius`, `gradient`(2색 체커 예외), `backdrop-filter`, `blur(`, 흐린 `box-shadow`/`text-shadow`, 투명도(opacity·반투명 색)로 상태 표현. 가림막 `--scrim`(k0 60% 단색 한 겹)만 예외.
- 그림자는 번짐 0의 팔레트 단색. 움직임은 `steps()`와 정수 px.

## 요소 7종 (`px/kit.css`, 테두리 = box-shadow 네 방향 2px)
- `.btn` 보조(44, p1). `.btn.primary` 주(b2). `.btn.gold` 보상(g2, `primary gold`도 같음). `.btn.danger`(r2). `.btn.buy` 구매(48).
- `.btn.quiet` 닫기·나중에(32, 면 없음·점선 밑줄). `.btn.icon`(40×40, 안에 글리프 16) · `.btn.sm`(32).
- 상태: 기본 / 눌림(아래로 4px, 받침 사라짐, 전환 없음) / 비활성(`:disabled` = k4 면·k3 글자·받침 없음) / 키보드 포커스(g2 고리 4px).
- `.chip` 수량·대상(32, `.active` = 금 면). `.tab`(44, `.active` = 종이 면 + 위 2px b2). `.card`(종이 + 받침 k1, 강조는 카드당 구매 버튼 1개).
- 선택 카드 `.ct-opt .plan-card`: 선택·추천은 `.picked` = g3 면 + g1 선. 스위치 `.setting-row input`(48×24, 켜짐 b2).
- 태그 `.tag`: 면 없음, 2px 선 자기 색, 카드당 1개. 작은 막대 8px(홈 k4, 채움 b2), 큰 막대 `.bar` 44px.
- 빨강 r2는 약정·위험·남은 시간·"탭" 분류 칩에만. 새로 얻음 칩 g2, 피버 배너·알림 점 or.
- 상태 면: 켜짐·보유·달성 = g3 면 + g1 선, 꺼짐·미보유·잠김 = k4 면 + k3 선 + 받침 없음(아이콘은 k3 mask 실루엣), 중립 = p1 + k1. p2 면은 쓰지 않는다. `grayscale` 필터 금지.
- 모든 `.btn` 글자는 `text-shadow: 1px 0 0 currentColor`(`.fb`와 같음), `.btn.quiet`만 예외. 보조 버튼(세트 보기·나중에 고르기·확률 보기)은 `.btn.quiet`.
- 선택 카드는 안에 `.pick-btn`("고르기", 누름은 카드가 받음)을 둔다. 서비스 카드 결합 태그는 1개, `nowrap`.
- 색 바꾸기는 변수(`--face --line --hi --drop --fg`)로. 새 버튼 색을 따로 만들지 않는다.

## 모달·토스트 (`m5.css`)
- 모바일 하단 시트, PC 가운데 520. p1 면 + k1 선 + k0 받침 8px. 제목 줄: 아이콘 32 + 제목(fs-l)만(✕ 없음). 닫기는 아래 버튼 한 곳, Esc·가림막 탭은 `overlay`의 `modal-close` 이벤트로 같은 동작.
- 토스트: 높이 40 이상, k1 면·p1 글자, 아래서 2단계로 올라옴.

## 버튼 색 규칙
- 주 버튼(창에서 다음으로 나아가는 하나) = 파랑 `primary`(b2 면 + k5 글자 + b1 받침). 모달 한 개에 하나.
- 보상을 받는 버튼(`받기`·사은품 `확인`·`좋아요`) = 노랑 `reward`(g2 면 + k0 글자 + g1 받침). 보조(`닫기`·`취소`·`또 열기`) = 밝은 면(p1 + k0 + k1 선). 위험(`초기화`·약정 해지) = r2.
- 어두운 바탕(k0/k1) 위 보조 버튼(결과 장면 `또 열기`·`또 10개`) = p1 면 + k0 글자 + k3 받침(선 없음). 옆 `확인`(g1 받침)과 높이·윗변·아랫변이 같고, 줄 좌우 끝은 결과 카드 바깥 끝과 같은 x.
- 모달 제목줄 = 맨 배경 + 24px 제목 + 아래 k1 2px 선. 보상·특전 창은 제목 왼쪽 12px 노랑 칩(`openModal` 옵션 `chip`, g3 면 + g1 선 + k0 글자)으로만 구분한다.

## 토스트
- 일반 알림 = k1 면 + k5 글자. 보상·획득 알림(`showToast(msg, true)`) = g2 면 + k0 글자 + g1 아래 그림자. 열림 알림(아이콘 있음) = k1 면 + k5 글자 + or 2px 테두리. 테두리는 모두 k0 2px, 모서리 0.
- 모양·위치: 글자 폭 + 좌우 12px 안쪽 여백의 가운데 정렬 칩(높이 36px, 15px 글자, 아이콘 24px). 모바일·PC 모두 방 윗변 4px 아래 가운데에 뜬다(머리의 회선 숫자를 가리지 않는다). 아래로 4px 간격으로 쌓고 최대 2개(오래된 것부터 지운다). 방 안 큰 글자(배너, `fx.banner` 하나로만 띄운다)는 방 안쪽 폭(좌우 12px 여백)을 넘지 않고, 토스트 띠(방 윗변 84px, PC 2배 방은 2배) 아래에서 시작해, 부제까지 방 아랫변 위 8px 안에 든다.
  글자가 넓으면 48→36→30→24px(PC 방 2배) 순으로 내리고, 그래도 넓으면 두 줄로 나눈다(자르지 않는다). 방 안 연타 글자는 k0 4방향 2px 외곽선, 36px 이하.
- PC 방 2배(폭 ≥ 1280·높이 ≥ 900): 토스트도 2배 — 글자 30px·높이 72px·아이콘 48px·좌우 여백 24px(`m6-desktop.css`). 방 1배면 15px 그대로.

## 단계적 공개 (`logic/unlock.ts`, `ui/unlockUi.ts`, `m9-unlock.css`)
- 새 게임은 방·서비스·독만 보인다. 조건이 처음 충족되면 하나씩 열리고(`state.unlocked`, 선택 필드), 한번 열리면 이사해도 유지. 이사한 저장·예전 저장은 연출 없이 열린 채 시작.
- 숨김은 `body:not(.ux-<id>)`가 대상을 `display:none`(자리 안 남김). 연출: `.ux-pop` steps 4프레임 + `fx.edge` 1회 + 토스트 "새로 열렸어요 · 이름" + 탭이면 주황 점(탭 열면 사라짐). 동시 충족은 600ms 간격, 모달·이사 장면 중엔 대기. 움직임 줄이기면 `.ux-pop` 없음.
- 탭 바는 `.tab-grp` 둘(왼쪽 서비스·공구 강화 / 오른쪽 상자·도감) 사이에 도구 버튼 자리. PC 단축키 1~4는 열린 탭만.
- 문턱값(`UNLOCK_RULE`, 시각은 `node tools/unlock-pace.mjs` 초당 4탭 기준):

| 상자 탭 | 포인트 ≥ 가격 절반 / 누적 1.5만 / 사은품 | 83초 |

## 카드 글자 규칙
- 굵은 글꼴이 없어 굵기(text-shadow 흉내) 대신 색과 모양으로 위계를 만든다: 이름 k0 15px → `Lv N` 칩(k1 면 + k5 글자 12px, `.card-lv`) → 수익 숫자 b2 15px(`.v-n`) + `/초` k2 12px(`.v-u`) → 막대 문구 k2 12px.
- 서비스 카드는 3줄: ① 이름 + Lv 칩 ② 수익 `+N/초` ③ 막대 문구. 결합 힌트(`x2까지 Lv 3 더`)가 있으면 ③의 막대 문구 자리를 대신 쓴다(4줄 금지). 결합·약정 칩은 아이콘 아래(`.card-lead`), 칩 글자는 `결합`을 뗀 `통신 x1.5`.
- 카드 하나에 숫자 줄은 최대 2줄, 설명문은 1줄. 핵심 값(효과)만 15px b2, 앞말·단위·보조 줄은 12px k2. 상자 가격은 b2. 값 줄은 `setVal(앞말, 숫자, 단위)`로 만든다.
- 공구 강화 카드의 기본+초당 분해는 탭 1회 줄을 눌러 여는 `배율 내역` 팝오버 아래에 한 줄로 보인다(모바일에도 보임).
- 마일스톤 배수는 카드에서 빼고 막대 문구와 `i` 상세로만 보인다. 위쪽 요약은 포인트 굵게, `/초`·보조 줄 12px 굵게.
