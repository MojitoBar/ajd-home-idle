# UI 가이드 (도트 키트)
설계 원본은 `DESIGN-PIXEL.md` 2절. 색·크기는 아래 토큰만 쓴다.

## 토큰 (`style.css :root`, 팔레트 24색은 `px/palette.css`)
- 색: `--k0..k5`(남색~흰) `--p1 p2`(종이) `--w1 w2`(나무) `--b1..b4`(파랑, 주색 b2) `--g0..g3`(금) `--r1 r2`(빨강) `--or --gn --pu --pk`. 초록(gn)은 그림 전용.
- 집 테마 4개: `--bg --bg-shade --on-bg --on-bg-dim`(바탕 위 글자만). 카드·모달은 항상 종이 `--paper`(p1) / `--paper-2` / `--ink`(k1) / `--dim`(k2).
- 키트 변수: `--face --line --hi --drop --fg`(요소 색), `--d: 2px`(도트 1칸).
- 간격 `--s1..s5` = 4·8·12·16·24. 받침(아래 6px)이 레이아웃에 안 잡히므로 형제 간격은 8 이상.
- 옛 이름(`--accent --gold-* --hot --sh-1 --fs-1..5 --r-*` 등)은 새 값으로 이어 주는 별칭이다. 새 코드에서 쓰지 않는다.

## 글자
- 본문 `--fs-m` 15/21 Galmuri14. 제목·숫자는 Galmuri11 Bold(`--f-bold`): `--fs-s` 12/16, `--fs-l` 24/28, `--fs-xl` 36/40, `--fs-xxl` 48/52.
- `.fb`(1px 덧칠 굵게)는 Galmuri14 15px 글자에만 쓴다. Galmuri11 Bold(12px)에 얹으면 획이 뭉친다. 아이콘은 도트 자연 크기의 정수배(16도트 32px, 24도트 48px)로만 쓰고 자리가 좁으면 뺀다.
- 줄높이 − 글자 크기는 짝수. `font-weight` 800~900 지정 금지(굵기는 Bold 글꼴로만). `font-synthesis: none`.

## 금지
- 0이 아닌 `border-radius`, `gradient`(2색 체커 예외), `backdrop-filter`, `blur(`, 흐린 `box-shadow`/`text-shadow`, 투명도(opacity·반투명 색)로 상태 표현. 가림막 `--scrim`(k0 60% 단색 한 겹)만 예외.
- 그림자는 번짐 0의 팔레트 단색. 움직임은 `steps()`와 정수 px.

## 요소 7종 (`px/kit.css`, 테두리 = box-shadow 네 방향 2px)
- `.btn` 보조(44, p1). `.btn.primary` 주(b2). `.btn.gold` 보상(g2, `primary gold`도 같음). `.btn.danger`(r2). `.btn.buy` 구매(48).
- `.btn.quiet` 닫기·나중에(32, 면 없음·점선 밑줄). `.btn.icon`(40×40, 안에 글리프 16) · `.btn.sm`(32).
- 상태: 기본 / 눌림(아래로 4px, 받침 사라짐, 전환 없음) / 비활성(`:disabled` = k4 면·k3 글자·받침 없음) / 키보드 포커스(g2 고리 4px).
- `.chip` 대상 선택(32, `.active` = 금 면). `.tab`(44, `.active` = 종이 면 + 위 2px b2). `.card`(종이 + 받침 k1, 강조는 카드당 구매 버튼 1개).
- 선택 카드 `.ct-opt .plan-card`: 선택·추천은 `.picked` = g3 면 + g1 선. 스위치 `.setting-row input`(48×24, 켜짐 b2).
- 태그 `.tag`: 면 없음, 2px 선 자기 색, 카드당 1개. 작은 막대 8px(홈 k4, 채움 b2), 큰 막대 `.bar` 44px.
- 빨강 r2는 위험·남은 시간·"탭" 분류 칩에만. 새로 얻음 칩 g2, 피버 배너·알림 점 or.
- 상태 면: 켜짐·보유·달성 = g3 면 + g1 선, 꺼짐·미보유·잠김 = k4 면 + k3 선 + 받침 없음(아이콘은 k3 mask 실루엣), 중립 = p1 + k1. p2 면은 쓰지 않는다. `grayscale` 필터 금지.
- 모든 `.btn` 글자는 `text-shadow: 1px 0 0 currentColor`(`.fb`와 같음), `.btn.quiet`만 예외. 보조 버튼(세트 보기·나중에 고르기·확률 보기)은 `.btn.quiet`.
- 선택 카드는 안에 `.pick-btn`("고르기", 누름은 카드가 받음)을 둔다.
- 색 바꾸기는 변수(`--face --line --hi --drop --fg`)로. 새 버튼 색을 따로 만들지 않는다.

## 버튼 색 규칙
- 주 버튼(창에서 다음으로 나아가는 하나) = 파랑 `primary`(b2 면 + k5 글자 + b1 받침). 모달 한 개에 하나.
- 보상을 받는 버튼(`받기`·사은품 `확인`·`좋아요`) = 노랑 `reward`(g2 면 + k0 글자 + g1 받침). 보조(`닫기`·`취소`·`또 열기`) = 밝은 면(p1 + k0 + k1 선). 위험(`초기화`) = r2.
- 어두운 바탕(k0/k1) 위 보조 버튼(결과 장면 `또 열기`·`또 10개`) = p1 면 + k0 글자 + k3 받침(선 없음). 옆 `확인`(g1 받침)과 높이·윗변·아랫변이 같고, 줄 좌우 끝은 결과 카드 바깥 끝과 같은 x.
- 모달 제목줄 = 맨 배경 + 24px 제목 + 아래 k1 2px 선. 보상·특전 창은 제목 왼쪽 12px 노랑 칩(`openModal` 옵션 `chip`, g3 면 + g1 선 + k0 글자)으로만 구분한다.

## 토스트
- 일반 알림 = k1 면 + k5 글자. 보상·획득 알림(`showToast(msg, true)`) = g2 면 + k0 글자 + g1 아래 그림자. 열림 알림(아이콘 있음) = k1 면 + k5 글자 + or 2px 테두리. 테두리는 모두 k0 2px, 모서리 0.
- 모양·위치: 글자 폭 + 좌우 12px 안쪽 여백의 가운데 정렬 칩(높이 36px, 15px 글자, 아이콘 24px). 모바일·PC 모두 방 윗변 4px 아래 가운데에 뜬다(머리의 회선 숫자를 가리지 않는다). 아래로 4px 간격으로 쌓고 최대 2개(오래된 것부터 지운다). 방 안 큰 글자(배너, `fx.banner` 하나로만 띄운다)는 방 안쪽 폭(좌우 12px 여백)을 넘지 않고, 토스트 띠(방 윗변 84px, PC 2배 방은 2배) 아래에서 시작해, 부제까지 방 아랫변 위 8px 안에 든다.
  글자가 넓으면 48→36→30→24px(PC 방 2배) 순으로 내리고, 그래도 넓으면 두 줄로 나눈다(자르지 않는다). 방 안 연타 글자는 k0 4방향 2px 외곽선, 36px 이하.
- PC 방 2배(폭 ≥ 1280·높이 ≥ 900): 토스트도 2배 — 글자 30px·높이 72px·아이콘 48px·좌우 여백 24px(`m6-desktop.css`). 방 1배면 15px 그대로.

## 단계적 공개 (`logic/unlock.ts`, `ui/unlockUi.ts`, `m9-unlock.css`)
- 새 게임은 방·공구 탭만 보인다. 조건이 처음 충족되면 하나씩 열리고(`state.unlocked`, 선택 필드), 한번 열리면 이사해도 유지. 이사한 저장·예전 저장은 연출 없이 열린 채 시작. 열림 요소와 조건은 `logic/README.md` "열림 규칙".

- 탭 바는 `.tab-grp` 둘(왼쪽 공구 강화·살림 / 오른쪽 상자·도감) 사이에 도구 버튼 자리. PC 단축키 1~4는 열린 탭만(공구·살림·상자·도감 순).

## 강타 게이지 띠 (`chargeUi.ts`, `heatUi.ts`, `m11-charge.css`)
- 게이지는 방 그림 안이 아니라 방 밖, 내구도 줄(`.px-strip`) 아래 전용 띠(`.charge`)다. 방 안 입자·글자·토스트가 못 덮는다. 겹침 순서 z 9(입자 캔버스 8 위, 말풍선·화살표 아래).
- 강타가 열린 뒤(가이드 5단계 이후, 가이드 끝난 저장)에는 띠가 늘 자리를 차지해 누를 때 아래가 안 밀린다. 잠긴 동안은 `body.g-no-charge`로 자리도 없다.
- 구성: 막대 24px(폭은 띠 폭 - 8, 2px 격자) + 아래 줄 16px(왼쪽 쉬는 안내 `꾹 눌러 강타` / 누르는 중 연속 칩, 오른쪽 열기 이름표 + 120px 줄). 눈금은 누르는 중에만 보인다.
- 뗀 직후(`.res`): 눈금이 멈춘 자리에 등급 색. 퍼펙트 노랑 테두리 + 83ms 번쩍 8프레임, 굿 파랑, 빗나감 어둡게. 이 동안 새 칸 위치는 미뤘다가 끝난 뒤(또는 다음 모으기 시작) 옮긴다.
- 얇은 띠(높이 700 이하 폰, 방 2배 PC 화면): 막대 16 + 열기 줄 8. 쉬는 안내는 접고 연속 칩·열기 이름표는 누를 때만 띠 위에 겹친다. 방 2배 화면은 띠도 `scale(2)`. 2배 화면에서 높이 1020 미만이면 자리를 안 차지하고 내구도 줄 사각형 위에 겹치며(한 줄 배치) 누르는 중·뗀 직후에만 보인다. 1020 이상이면 띠가 내구도 줄 아래 제 자리를 늘 차지하고, 같은 한 줄 배치(연속 칩 | 타이밍 막대 | `파워` 이름표 | 열기 줄, 칩·이름표 자리는 숨겨도 유지)라 누르기 전후로 아무것도 안 밀린다. 이때 이사 줄·가이드 줄 2배 기준은 높이 1084.
- 연쇄 재생 중에도 꾹 누르면 띠는 평소처럼 켜져 눈금이 움직인다(띠는 방 밖이라 방 안 연쇄 숫자와 안 겹침). 연쇄 도중의 일반 탭·러시 자동 탭은 그대로 막힌다. 연쇄가 끝나기 전에 떼면 판정은 뗀 순간의 눈금으로 정하고, 뗀 즉시 남은 칸을 2틱(약 0.07초)에 몰아 처리해 `N연쇄!`·합계를 90ms 보여 준 뒤 새 강타를 낸다(`chainHurry`·`chainFinish`, 이전 연쇄의 합계·상금·보상 처리는 평소대로). 새 강타의 판정 글자는 그 뒤에 뜨므로 이전 연쇄 글자와 안 섞인다.
- 말풍선: 9단계 `게이지를 노란 칸에 맞춰 놓아요`·열기 안내는 띠 바로 위(꼬리가 띠를 가리킴), 5단계 `꾹 눌렀다 떼면 강타!`는 방 안 상자 위. 방 안 판정 글자·연출은 그대로.

## 실드 칸 (`chargeUi.ts`, `m11-charge.css`)

## 안내 창·토스트
- v9 안내 창: 옛 저장(`state.notice`)이면 시작할 때 한 번 모달 "집 키우기가 바뀌었어요"(닫기 없음, 주 버튼 `확인` 하나). 확인하면 `notice`를 지우고 저장.
- 복귀 러시 토스트: 30분 넘게 비웠다 오면 보상 토스트(`showToast(msg, true)`, g2 면) "다녀오셨어요! 15초 동안 자동으로 쳐 줘요". v9 안내가 떠 있으면 확인 뒤에 한 번만. 러시 중에는 방 테두리 파랑 깜빡임 + 피버 칩 위 `자동 N초` 칩(`.rush-tag`, 999초 위는 `자동 N분` 올림, 아랫변 막대는 0이 된 뒤 쌓인 최대값 대비 남은 비율). 연쇄 재생 중에는 남은 시간이 줄지 않는다.
- 특별 상자 설명(`specialUi.ts`): 공구 강화 탭 돋보기 카드 이름 줄의 `i` 버튼(`.gear-info`, 32px·누르는 영역 48px)이 "특별 상자" 창을 연다 — 지금 확률(`gearEffects.specialRate`)·"집마다 처음 20개에는 안 나와요"·종류별 줄(작은 상자 그림 + 이름 + 실제 수치 효과), `닫기`(보조) 하나, ✕ 없음.
- 처음 만날 때 토스트: 종류별 평생 한 번 일반 토스트 "황금 상자 · 보상 xN" 등(한 번에 최대 2종, 나머지는 다음 기회). 본 종류는 별도 키 `ajd-home-idle:seen-special`에만 적고 게임 저장은 건드리지 않는다. 가이드 진행 중에는 띄우지도 적지도 않는다.

## 가이드 (`guideUi.ts`, `guideFx.ts`, `guidePoint.ts`, `guide.css`, 단계표 `logic/guide.ts`)
- 가이드 줄 `.guide-row`: 방 아래 띠와 이사 줄 사이, 종이 면 + k1 선. 위 줄 = 주황 `가이드 n/18` 칩 + 진행 숫자 + 노랑 보상 칩, 아래 = 지금 할 일(15px, 넘치면 12px·짧은 문구), 맨 아래 8px 막대. 끝나면 `hidden`.
- 낮은 폰(높이 759 이하)은 한 줄(30px): 칩 + 문구 + 숫자(자리가 모자라면 숫자도 뺌), 보상 칩 없음, 막대 4px. 이사 줄·큰 숫자 줄도 `body.guiding`이 낮춘다.
- 단계 완료 연출: 줄이 "완료!" + 가득 찬 주황 막대로 붙잡히고(`celebrateHold`) 방 안 머리글 "가이드 N 완료!"(+ 주황 부제 칩), 코인, 열린 요소 주황 테두리, 선물 상자 결과. 번쩍임이 끝나면 다음 문구로 바뀐다.
- 화살표 `.gd-point`(`syncGuidePoint`): 눌러야 할 요소 위(안 되면 아래·옆)에 주황 면 + k0 외곽선 도트 화살표(2px 도트 SVG, `steps()`로 4px 까딱). `pointer-events: none`, z-index 20.
  대상: 공구 강화·오함마·영구 공구 버튼, 상자 탭 뽑기 버튼, 13단계 특전 상자 뽑기 버튼(상자 탭 -> `.perkbox-buy`), 살림 탭, 총 배율 칩, 이사 버튼. 버튼이 다른 탭에 있으면 그 탭 버튼, 탭 내용 영역 밖이면 가장자리에 붙여 방향만 가리킨다.
  살 돈이 모자라면 가리키지 않는다. 방 안 행동 단계는 4초 동안 입력이 없을 때만 상자 아래에서 위를 가리킨다. 모달·상자 뽑기·이사 장면·단계 완료(줄이 "완료")에서는 숨기고, 가이드가 끝나면 뜨지 않는다.
- 말풍선: 가이드 중 방 안에는 지금 단계의 행동 안내 하나만 뜬다(1단계 첫 탭 `tapHint`, 5단계 강타, 6단계 급소가 뜰 때마다, 9단계 퍼펙트 첫 성공 전). 열기 안내는 가이드가 끝난 뒤. 방 안 큰 머리글·창·장면이 있으면 숨긴다.
  가이드가 끝난 저장의 말풍선(`chargeDone`·`weakDone`·`heatDone` 플래그로 한 번씩)은 예전과 같다.

## 특전 상자 (`box.ts`, `strategyUi.ts`, `col.css`, `m5.css`, 아이콘 `tools/make-perk-icons.py`)
- 상자 탭은 뽑기 2종: 수집 상자(`.box-hero`, 크림 면, "도감 배율이 올라요" 칩)와 특전 상자(`.perkbox-card`, b4 하늘색 면 + b2 선, "특전 레벨이 올라요" 금색 칩). 두 카드의 면 색과 칩 문구로 한눈에 가른다. 특전 상자 카드는 `perkBoxUnlocked`가 false면 `hidden`(가이드 13단계에서 열림, 열릴 때 상자 탭에 알림 점).

## 공구함 덱 (`deckUi.ts`, `m13-deck.css`, 설계 `DESIGN-DECK.md`)
- 카드 줄 `.deck-row`(높이 60): 이사 블록 맨 위, 이사 줄 위. 칸 3개 48x48(아이콘 32, 간격 8) + 종이 면 + 태그 색 2px 테두리(`--tag-*`: 정밀 b2·연쇄 or·특별 pu·러시 b4·피버 pk, 빨강 안 씀) + 받침. 칸 아래 8px에 충전 막대 4px(`.deck-bar`, 채움 b2 · 꽉 차면 g3, 1도트 단위 `steps(6)`). 오른쪽 `.deck-side`: `공구함 ×N` 24px(`fx.roller`, 배수가 1이면 `.calm` 흐린 글자) + 12px `빈 칸 N`/`칸 가득`. 빈 칸은 점선. 첫 집(`moves 0`)은 줄이 없다(`body.has-deck`도 없음). 누르면 공구함 창.
- 카드 고르기 창: `openPerkPick`의 `pcard` 그대로(칩 = `카드`, 카드 칩 = 태그). 이미 낀 카드는 `maxed`(고를 수 없음). 칸이 차면 같은 창 안에서 `바꿀 칸 고르기`(낀 카드 3장, `돌아가기`). 묶음이 여럿이면 하나 끝낸 뒤 이어진다. 효과 글이 긴 카드가 잘리지 않게 칸 높이는 글에 맞춘다.
- 알림: 대기 묶음이 있으면 `moveExtra`에 노란 `카드 고르기`(`.perk-alert` 재사용이라 PC 2배·높이 규칙이 같이 따라간다)와 공구 강화 탭 주황 점. 강타·연쇄 중에도 창을 저절로 열지 않는다.
- 발동 연출(강타 1회에 카드당 1번): 칸이 위로 4px 튐(`fx.pxFrames`) + `fx.edge(g3)` + 칸 위에 `×N` 24px(g3 + k0 외곽선, 칸 한가운데에서 8px 올라감). `gain`이 있으면 칸에서 점수판으로 `fx.coinShower`. 여러 장은 왼쪽 칸부터 90ms. 탭 수에 곱하는 카드(`mult`)는 뗀 순간, 보상 카드는 연쇄 재생이 끝난 뒤(`chainPlaying()` 대기). 움직임 줄이기: 테두리 색 300ms + `×N` 제자리 1초. 방 안 큰 글자(`fx.headline`)는 쓰지 않는다. 효과음은 `sfx.milestone`(동시 3개까지)·코인은 `coinShower` 안의 `sfx.reward`.
- 충전 연출(`deckCharge`, 연쇄 재생이 끝난 뒤 `whenChainDone`, 같은 강타에 발동 카드가 있으면 400ms 뒤): 눈금은 막대만 오른다(글자 없음). 카드 완성 = 칸 튐 + 방 `fx.edge(g3)` + 칸 위 `×4` + 공구함 숫자 껑충·g3(그동안 숫자는 강타 전 값으로 붙든다) + `sfx.milestone`. 배율이 10의 거듭제곱을 넘으면 카드 줄 `fx.edge(or)` + `sfx.breakthrough`. 덱이 다 차면 `fx.banner('공구함 완성 ×64')` 한 번(notice 줄에 선다). 공구함 창: 맨 위 `공구함 배율`(36px) · 카드마다 막대 + `지금 ×N / 최대 ×4` + 충전 방법 한 줄(`pr-how`). 고르기·교체 창에도 충전 방법, 교체 화면은 칸마다 지금 배수 + 충전 소멸 안내. 배율 내역 창은 `공구함(이 집)` 줄이 `총 배율` 바로 아래(머리 칩은 영구 배율만).
- PC: 카드 줄이 있으면 이사 블록 2배는 높이 1110 이상(알림 버튼이 떠 있으면 1200 이상)에서만, 그 아래는 1배. 방 2배·높이 900~943(1440x900)은 `특전 고르기`·`카드 고르기` 버튼이 카드 줄 오른쪽에 나란히 한 줄로 올라가고(그동안 `.deck-side`는 숨김) 힌트 줄·바닥 여백·피버 띠 위아래 여백이 접힌다(줄 60 때문에 세로 스크롤 없음).
